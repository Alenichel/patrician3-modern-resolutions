PATRICIAN III MODERN RESOLUTIONS 1.1.2

REQUIREMENTS
Windows 10/11, Steam, and your own English copy of Patrician III (1.1).
Supported game resolutions: 1920x1080, 1920x1200, 2560x1080, 2560x1440,
and 3440x1440. Choose Resolution in the launcher; the current display is the default.
UI scale remains 100%; Windows display settings are not changed.
1920x1080 and 3440x1440 are gameplay verified. The other three profiles have
passed automated checks and still require gameplay validation.
No Python, additional libraries, mod loader, or compiler installation is required.

START PLAYING
1. Extract the ZIP to a folder of your choice.
2. Open Patrician3ModernResolutions.exe.
3. The launcher searches your Steam libraries. Use Browse if necessary.
   Select Resolution; your current display resolution is selected by default
   when supported. Otherwise select one of the supported profiles manually.
4. Close the game, click Launch mod, and approve the UAC prompt.
5. Wait for Patch active before loading a game.
   Keep 1280x1024 selected in the options: it is the original label of the
   resolution slot used by the patch. The main menu keeps its original size.

Always use this launcher for modded sessions. Steam's normal Play button does
not apply the memory patch. The game executable is not modified on disk.
Steam's first launch may open P3Setup: complete it with OK, close the game,
and then try the launcher again.

RESTORE
Close the game, open the same EXE, and click Restore original.
Backup: game folder/mods-ultrawide/backup-originali. Do not delete it.
Legacy storage names are retained so previous backups remain usable.
Save files are not changed. Mods using the same INI/image files may conflict.

TROUBLESHOOTING
Read the launcher or %LOCALAPPDATA%/Patrician3ModernResolutions/last-operation.log.
Unknown executable builds are rejected before any game files are changed.
The launcher is not digitally signed; Windows may ask you to verify its source.
Compatibility is limited to the configuration stated above.
